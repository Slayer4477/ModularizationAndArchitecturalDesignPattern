# BookNest App

This is a simple Android app for books. It has three main parts:
1. Catalog - see all books and add them to favorites.
2. Favorites - see your favorite books.
3. Checkout - buy a book with your email.

We used Kotlin, Jetpack Compose, and architectural patterns.
